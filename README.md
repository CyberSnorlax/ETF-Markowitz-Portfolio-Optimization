# ETF-Markowitz-Portfolio-Optimization

In this project, I replicated Vice President elect J.D. Vance's notable ETF portfolio strategy, which includes major U.S. index funds and a diverse range of assets classes, as a starting point for my asset allocation. Then I utilizied Markowiz's Modern Portfolio Theory with Yahoo Finance data to find the optimal portfolio for a given risk-aversion. The CML (Capital Market Line) and Efficient Frontiers were then calculated to reflect this optimization.
